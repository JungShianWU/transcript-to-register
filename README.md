# 謄本轉地號清冊

把地政**電子謄本 PDF**（土地＋建物）轉成**地號清冊 Excel**。

整個工具就是一個 HTML 檔，雙擊用瀏覽器開啟即可，不用安裝，也不需要網路。

- 可一次選多份謄本 PDF，土地、建物、共有部分會自動對應到同一個清冊。
- 內建兩種範本可選：**作者範本**（權屬＋分配表，預設）與**通用範本**（地號清冊）；也可以上傳自己的地號清冊範本。
- 每次產出都會做持分檢核，有問題會在畫面上列出。

> 本專案由 Jacky 與 Anthropic 的 AI 助理 [Claude](https://claude.ai) 協作開發。

## 快速上手（不需要任何技術背景）

> 只要會用瀏覽器就能用。不用安裝軟體、不用註冊帳號、不用網路。

### 第一步：拿到工具檔案（只要做一次）

整個工具只有**一個檔案**：`謄本轉地號清冊.html`，兩種內建範本也包含在裡面，不需要再下載其他東西。

1. 在這個網頁往上捲到最上面，找到綠色的 **`<> Code`** 按鈕，點一下。
2. 在跳出來的選單最下面，點 **`Download ZIP`**。
3. 會下載一個叫 `transcript-to-register-main.zip` 的壓縮檔，到電腦的「下載」資料夾。
4. 在這個壓縮檔上**按右鍵 →「解壓縮全部」**（Mac 直接按兩下即可）。
5. 打開解壓縮出來的資料夾 → 再打開裡面的 **`dist`** 資料夾 → 就會看到 **`謄本轉地號清冊.html`**。
6. 把這個檔案複製到桌面。其他檔案都用不到，可以刪掉。

### 第二步：開啟工具

- 在 `謄本轉地號清冊.html` 上**按兩下**，它會用瀏覽器打開。
- 如果是用其他程式打開（例如記事本），請改成：**按右鍵 →「開啟檔案」→ 選 Google Chrome 或 Microsoft Edge**。
- 看到標題「謄本轉地號清冊」和綠色的「離線執行」標籤，就代表開啟成功。

### 第三步：產生清冊

1. **選範本**：在左邊的框點選要用哪一種。不確定就用預設的「作者範本」。
   - **作者範本**：權屬＋分配表，含地主分回與補貼試算欄位。
   - **通用範本**：地號清冊，土地、建物、公設逐欄列出。
   - **上傳自己的範本**：選了之後會出現上傳框，範本需為地號清冊格式。
2. **選謄本**：點右邊的框，選電子謄本 PDF。可以一次選很多份，也可以直接把檔案拖進框裡。
   土地謄本、建物謄本最好一起放，建物資料才會填進去。
3. 按 **「產生清冊」**，等幾秒鐘。
4. 看一下畫面上的結果：
   - **綠色 ✓「檢核全部通過」**：可以直接用。
   - **黃色「需要確認」**：列出要人工看的地方，例如持分加起來不等於 1、缺少某戶的建物謄本。請對照謄本確認。
5. 按 **「下載 Excel」**，清冊就會存到「下載」資料夾。

### 第四步：打開 Excel 後要做的事

- **用作者範本時**：「公告地價」（I 欄）請自行填入；右邊「地主分回、應負擔興建成本、地主分回」的總數（第 2、4 列）原本連到其他試算檔，請自行填入，各地號的分回會依土地坪數自動分攤。
- **用通用範本時**：在第 1 列的兩個**黃色格子**填入這個案子的「基準容積率」和「容積獎勵」（例如 300%、80%），允建容積、權利價值、分配比例就會自動算好。
- **立體價差**（BD 欄）預設都是 1，請依樓層自行調整。
- 正式使用前，請再對照謄本正本確認一次。

### 常見問題

| 狀況 | 原因與處理 |
|---|---|
| 顯示「這份 PDF 曾經過『列印成 PDF』轉存」 | 這份電子謄本在某個環節被用「列印 → Microsoft Print to PDF」之類的方式重新存過，文字變成了圖形。轉存可能在你拿到檔案之前就發生了。請向來源索取從地政網路申領系統下載的**原始檔**，或重新申請。 |
| 顯示「這份 PDF 沒有文字（掃描檔或影像檔）」 | 這份 PDF 是掃描或拍照產生的，裡面只有圖片（用滑鼠也選不到字）。請改用地政事務所網路申領的**電子謄本**。 |
| 顯示「是電子謄本，但標題或格式與目前支援的不同」 | 這份謄本的格式工具還不認得，請回報給維護者。 |
| 顯示「沒有讀到任何土地謄本」 | 清冊以地號為單位，至少要放一份**土地**謄本。 |
| 「需要確認：地上建物 ○○○ 沒有建物謄本」 | 只放了土地謄本。把對應的建物謄本 PDF 一起選進去，再按一次「產生清冊」。 |
| 下載後找不到檔案 | 到電腦的「下載」資料夾找，檔名開頭是「地號清冊_」。 |
| 住址欄是空的 | 電子謄本上的住址是圖片，工具不會讀取，這是正常的。 |
| 會不會把資料傳到網路上？ | 不會。工具完全在你的電腦上執行，不會連線網路，就算拔掉網路線也能用。 |
| 工具更新了怎麼辦？ | 重做一次「第一步」下載新版，用新檔案取代桌面上的舊檔即可。 |
| 按兩下打開後畫面是一堆程式碼 | 被其他程式開啟了。請在檔案上按右鍵 →「開啟檔案」→ 選 Chrome 或 Edge。 |

## 使用方式（摘要）

1. 開啟 `dist/謄本轉地號清冊.html`（Chrome 或 Edge）。
2. 選範本：作者範本（預設）、通用範本，或上傳自己的地號清冊範本 `.xlsx`。
3. 選謄本 PDF，可多選或直接拖曳。
4. 按「產生清冊」，確認畫面上的對應結果與「需要確認」項目。
5. 按「下載 Excel」。

> 只支援**有文字層的電子謄本**。掃描檔、拍照檔沒有文字層，無法辨識。
> 電子謄本中的所有權人住址是圖片，不會被讀取。

## 填寫規則

**區塊與排列**
- 每筆地號一個區塊，從第 5 列開始，依該地號所有權人在謄本上的順序逐列排列。
- 地號（D）、面積（E）跨整個區塊合併。
- 建物依「建物坐落地號」歸到土地；建物所有權人不在土地所有權部時，列在該區塊最後（土地持分留空）。

**特殊持有方式**
- **同一人多戶建物**：第二戶起另起一列，土地持分只算一次（留空）。
- **公同共有**：依「其他登記事項：登記次序 XXXX 至 YYYY 公同共有」判斷同一組共有人，排在一起；持分只寫一次，H～N 欄（持分、容積率、持有面積、允建容積）跨列合併。
- **建物部分持有**：共有部分持分會乘上建物持分（例：1/6 × 1/2 = 1/12），主建物坪數公式改用 `R*0.3025*S/U`。

**建物欄位**
- 附屬建物依用途分欄：騎樓→W、陽臺等→AB、平台→AG、夾層→AI、屋突→AK、防空避難室→AM。
- 共有部分前兩個填在 AO～AT、AU～AZ；若整份清冊該組只有一個共有部分建號，標題列會自動改成該建號。
- 第 3 個以後的共有部分，每個一組 7 欄（建號、面積、持分、持有㎡、持有坪）加在工作表最右邊，預設隱藏；點欄位上方的「+」即可展開。這些面積都會計入建物總面積（BA）。
- 樓次（BB）格式為「層次/總層數」，例：`2/5`、`B1/5`。
- 立體價差（BD）預設 1，請依案件自行調整。

**作者範本（權屬＋分配表）**
- 一筆地號一個區塊：地號、使用分區、面積、公告現值／地價、持分比例、分回試算（AJ～AR）跨整個區塊合併；A 欄地段相同的區塊合併成一格。
- 每列一位所有權人（L 欄，AI 欄同一人）：
  - 土地持分（V）＝ 土地坪數 × 權利範圍，例：`=$E$5*900/5400`；公同共有只寫在第一位並跨列合併。
  - 建號（W）依範本格式寫成 8 位數，例：03627-000 → `03627000`。
  - 主建物（Z）、附屬建物（AB）、共有（AD）以算式寫出，例：共有 `=22.86*582/5400+10.61*3489/5400`；**共有部分不論幾筆都加總在同一格**。建物為部分持有時，算式會乘上建物持分。
  - 搬遷費（AS）預設 5、租金補貼用 AU 欄的單價、意願調查（AV）預設 1，可自行調整。
- 最後一列是合計列，總計範圍會依實際列數自動調整。
- 表頭年度依謄本的公告現值年度自動更新；列印頁首自動寫上案名，頁尾寫上製作日期（民國）。
- 公告地價（I 欄）與第 2、4 列的分回總數需自行填入。

**通用範本（地號清冊）**
- 由 `scripts/make_template.py` 從零產生，不含任何特定機構或案件的資料、logo 或外部連結。
- 欄位位置與常見地號清冊一致：土地標示部 A～O、建物標示部 P～BC、權利價值 BD～BF。
- 容積率、容積獎勵是第 1 列的兩個黃色輸入格（R1、U1），填一次，所有列的允建容積、權利價值、分配比例都會跟著算。
- 權利價值 = 允建容積 × 立體價差；分配比例 = 權利價值 ÷ 全部權利價值合計。

**使用自有範本時**
- 第 5 列以下的 A～CE 欄會重新產生，標題列與 CF 欄以後的試算區保留不動。
- 範本中權利價值部以後的公式原樣沿用；範本連到其他檔案而顯示 `#REF!` 的公式不會修正。

**他項權利（接在各列最右邊）**
- 不論選哪一種範本，土地與建物謄本「他項權利部」的資料都會接在清冊主表的最右邊，跟著對應的那一列，不另外開分頁。
- 每筆他項權利一組欄位：權利種類、登記次序（第幾順位）、權利人、權利價值、擔保債權確定期日、清償日期、登記日期、登記字號、登記原因、設定權利範圍。
- 同一列有多筆時再往右加一組，表頭依序標示「他項權利（一）」「他項權利（二）」…。
- 同一筆設定（收件年期＋字號相同）同時登記在土地與建物上時，放在該建號那一列；只設定在土地上的，放在該所有權人於該地號的那一列；同一筆設定涵蓋多筆地號時，各地號的列都會列出。
- 「第幾順位」依同一所有權人持分上的設定先後計算。
- 金額顯示為「新台幣…元」，日期為民國格式；沒有擔保債權確定期日的舊式抵押權，改顯示存續期間。

**其他**
- 列印範圍會自動延伸到最後一列資料。
- 產出檔案的作者與最後修改者設為 `Jacky`（在 `src/ui.html` 的 `AUTHOR` 修改）。
- 網頁底部列有使用聲明、隱私聲明、資料來源與開源元件授權。

**自動檢核（列在「需要確認」）**
- 土地持分合計是否等於 1（公同共有只計一次）
- 土地謄本上的地上建物是否都有建物謄本
- 共有部分在各主建物的持分合計是否等於 1
- 公同共有人的權利範圍是否一致
- 建物樓層是否能判斷

## 專案結構

```
src/
  core.js          解析謄本、對應清冊列、寫入 xlsx（瀏覽器與 Node 共用）
  ui.html          畫面；建置時會把程式與範本內嵌進來
template/
  author.xlsx      作者範本（權屬＋分配表，預設）
  generic.xlsx     通用範本（地號清冊，由 make_template.py 產生）
scripts/
  build.js         打包成 dist/ 單一 HTML
  cli.js           命令列版本
  make_template.py 產生通用範本
dist/
  謄本轉地號清冊.html   建置結果，直接開啟使用
```

## 開發

需要 Node.js 18 以上。

```bash
npm install
npm run build        # 產生 dist/謄本轉地號清冊.html
```

命令列版本（不開瀏覽器，適合批次處理）：

```bash
node scripts/cli.js -o 清冊.xlsx 謄本1.pdf 謄本2.pdf
node scripts/cli.js -o 清冊.xlsx -t generic 謄本/*.pdf            # 通用範本（預設為作者範本）
node scripts/cli.js -o 清冊.xlsx -t 我的範本.xlsx --author 名字 謄本/*.pdf
```

### 修改內建範本

**作者範本**：直接用 Excel 修改 `template/author.xlsx` 的表頭與樣式後重新 `npm run build`。程式只讀取第 1～4 列（表頭）以及第 5、6、14、15、16 列的樣式（區塊首列、中間列、末列、合計列、附加列），資料與公式由程式產生。存檔前請確認檔案作者、外部連結與名稱定義沒有夾帶其他資料。

**通用範本**：修改 `scripts/make_template.py` 後重新產生並打包（需要 Python 3 與 `openpyxl`）：

```bash
pip install openpyxl
python3 scripts/make_template.py
npm run build
```

也可以直接把其他地號清冊範本存成 `template/generic.xlsx`。程式依下列位置讀取範本格式，替換時請維持：

- 第 1～4 列為標題列；資料從第 5 列開始。
- 第 5 列：區塊第一列的樣式，以及各欄公式（如 `L5 = $E$5*0.3025*H5/J5`）。K5、M5 可以是常數或公式。
- 第 6 列：區塊中間列的樣式；第 11 列：區塊最後一列的樣式。
- 資料區為 A～CE 欄；CF 欄以後（右側試算區）不會被改動。

若改用自有範本當內建範本，放進版控前請先清除範例資料、檔案作者、logo 與外部連結。
